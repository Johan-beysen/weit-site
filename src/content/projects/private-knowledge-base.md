## Wat het is

Een persoonlijke kennisbank gebouwd rond MkDocs Material om technische kennis, pentest-notities, hacking manuals, netwerkdocumentatie en systeembeheerreferenties centraal te beheren. Opgezet als een statische documentatieomgeving: snel, doorzoekbaar, versiebeheerbaar en geschikt om continu uit te breiden.

Bewust niet opgezet als losse verzameling notities, maar als een gestructureerde documentatiehub met navigatie per domein. De inhoud is onderverdeeld in ethical hacking, web application security, API security, tooling, Linux, enterprise networking, databanken en regelgeving.

De focus ligt op bruikbare operationele kennis: stappenplannen, cheatsheets, testmethodes, toolreferenties en technische context die tijdens labo's, pentests, voorbereiding of rapportage snel teruggevonden moet worden.

## Toegangsbeveiliging

Omdat de kennisbank gevoelige inhoud bevat — hacking manuals en pentest-technieken — staat de gepubliceerde versie achter **Cloudflare Zero Trust**. De site is niet publiek toegankelijk: alleen gebruikers die expliciet toegang gekregen hebben, kunnen de documentatie raadplegen.

Zo blijft de workflow praktisch bruikbaar als online kennisplatform, zonder gevoelige security-inhoud open op het internet te zetten. Operational security als ontwerpkeuze, niet als afterthought.

## Technische stack

| Tool | Rol |
|------|------|
| MkDocs Material | Documentatieframework met ingebouwde zoekfunctie, syntax highlighting, tabs en admonitions. |
| Markdown | Schrijf- en onderhoudsformaat — plain text, versiebeheerbaar, snel te bewerken. |
| mkdocs.yml | Gestructureerde navigatie — domeinen, secties en hiërarchie centraal beheerd. |
| Custom CSS | Eigen dark theme in lijn met persoonlijke branding. |
| GitHub | Versiebeheer — elke aanpassing bijgehouden, rollback mogelijk. |
| Cloudflare Zero Trust | Toegangslaag rond gevoelige content — identity-based access, geen open internet exposure. |

## Waarom dit project

De kennisbank is gebouwd voor mijn eigen leer- en werkproces als ethisch hacker: snel kunnen zoeken, procedures hergebruiken, commando's kopiëren, concepten structureren en kennis uit opleidingen, labo's en praktijkervaring centraliseren.

Dit project toont mijn aandacht voor kennisbeheer en operational security. Ik documenteer niet alleen technische kennis, maar zorg er ook voor dat gevoelige informatie correct afgeschermd blijft.
